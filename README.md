# Daylight — Daily Planner

**A focused daily planning workspace for the tasks that matter.**

🔗 Live demo: https://deekshith1327.github.io/daily-planner/

## Features

- Add, complete, and remove daily priorities
- See a live completion count and progress ring
- Keep today's list in browser storage
- Responsive layout for desktop and mobile

## Run locally

Requires Node.js 18 or later.

```sh
npm start
```

Then open [http://localhost:3000](http://localhost:3000). The local Node server also saves app state to `data.json`; the GitHub Pages version stores data in this browser.
